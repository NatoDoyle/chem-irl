# Archive

Files in this directory are historical snapshots — phase-completion
records, an old architecture pivot, dependency/deployment status frozen
in time, and superseded documentation. They are NOT the current source
of truth for any system. Read with caution; many references to files,
commands, and decisions in here have since been superseded.

The newest file in this directory is from 2026-03-22. If you are looking
for active documentation, see [../README.md](../README.md) and the
top-level [CLAUDE.md](../../CLAUDE.md) for the canonical map.

## Why keep these at all

They occasionally answer "why did we build it this way?" or "what did
the pre-pivot architecture look like?" — useful context when reading
old code, less useful as guidance for new work.

If a file here is contradicted by anything in the active docs or by the
current code, the active source wins. Always.
